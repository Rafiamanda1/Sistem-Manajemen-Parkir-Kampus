# Sistem-Manajemen-Parkir-Kampus

Fitur Utama (Core Features):Tambah & Hapus Data: 
Mencatat plat nomor, jenis kendaraan (validasi khusus "Mobil" atau "Motor"), serta waktu masuk dan keluar.   
Hitung Biaya Parkir: Menghitung tarif parkir secara otomatis berdasarkan durasi waktu menggunakan fungsi dengan parameter.   
Cari Kendaraan: Memungkinkan pencarian data kendaraan secara spesifik berdasarkan plat nomor.   
Sorting Kendaraan: Mengurutkan daftar kendaraan berdasarkan waktu masuk atau jenis kendaraan.   
Simpan/Muat File Teks: Menyimpan dan memuat data secara otomatis ke file teks (parkir_data.txt) agar data tidak hilang.   
Statistik Harian: Menampilkan rekapitulasi total kendaraan yang tercatat serta total pendapatan harian.   
Daftar Parkir Aktif: Menampilkan daftar kendaraan yang saat ini masih berada di area parkir (belum keluar).
